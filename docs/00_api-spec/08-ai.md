### GET `/api/v1/recommendations`

사용자 벡터 기반으로 맞춤 상품을 추천합니다.

**처리 흐름**
1. Redis 캐시 조회 → 캐시 HIT 시 즉시 반환
2. 사용자 벡터 기반 추천 (Elasticsearch kNN)
3. GPT 추천 이유 비동기 생성 (최초 요청 시 `PENDING` 반환)
4. 결과가 아직 생성 중이면 `status: PENDING`, 완료 시 `status: COMPLETED`

**Response** `200 OK`
```json
{
  "status": "COMPLETED",
  "recommendations": [
    {
      "productId": "uuid",
      "title": "제주도 여행 패키지",
      "reason": "사용자의 여행 관심사와 유사한 상품입니다."
    },
    {
      "productId": "uuid",
      "title": "서울 요리 클래스",
      "reason": "최근 조회한 쿠킹 클래스와 연관된 추천입니다."
    }
  ]
}
```

**status 값**

| 값 | 설명 |
|----|------|
| `PENDING` | GPT 추천 이유 생성 중 (Polling 필요) |
| `COMPLETED` | 추천 이유 포함 완전한 결과 반환 |
| `FAILED` | 추천 처리 실패 |
